Introdução ao HTML

HTML (HyperText Markup Language) é a espinha dorsal de qualquer página web. É através dele que definimos títulos, parágrafos, imagens e links que estruturam a internet.

Exemplo Estrutural:

<!DOCTYPE html> <html> <body> <h1>Bem-vindo ao W3Schools Pro</h1> <p>O seu clone está mais moderno e bonito!</p> </body> </html>

Elementos HTML

Elementos organizam e envelopam blocos visuais. Eles usam tags de abertura e fechamento para gerenciar as regras estruturais da tela.

Exemplo:

<a href="https://google.com">Visitar o Buscador</a>

Introdução ao CSS

O CSS (Cascading Style Sheets) transforma códigos HTML brutos em interfaces ricas, aplicando fontes, cores personalizadas, grids e animações sofisticadas.

Exemplo de Design:

body { background-color: #f8fafc; color: #0f172a; }

Sintaxe CSS

Regras limpas de CSS mapeiam propriedades visuais associadas a seletores HTML organizados.

Exemplo:

.card-w3 { border-radius: 12px; box-shadow: 0 4px 20px rgba(0,0,0,0.1); }

Introdução ao JavaScript

JavaScript controla o comportamento da página. Com ele, você valida formulários, cria ações dinâmicas ao clicar em botões e altera elementos em tempo real.

Exemplo Dinâmico:

const site = "W3Schools Pro"; console.log(`Bem vindo ao ${site}!`);

Variáveis em JavaScript

Armazene dados dinâmicos utilizando escopos seguros através das diretrizes modernas do ECMA.

Exemplo:

let curtidas = 1500; const ativo = true;

Introdução ao PHP

O PHP é uma linguagem focada no Back-End. Ele processa dados no servidor antes de enviar a página para o navegador do usuário.

Exemplo de Script PHP:

<?php echo "Olá! Este texto foi processado no Servidor."; ?>

Sintaxe PHP

Os blocos de código PHP começam com <?php e terminam com ?>. Suas variáveis sempre começam com o símbolo \$.

Exemplo de Sintaxe:

<?php \$txt = "W3Schools"; echo "Eu adoro o \$txt!"; ?>

Introdução ao MySQL

O MySQL é um sistema de banco de dados relacional que organiza e armazena as informações do seu site de forma rápida e segura através de tabelas.

Exemplo de Consulta SQL:

SELECT * FROM usuarios WHERE status = 'ativo';

Criar Tabelas (Create Table)

A instrução CREATE TABLE estrutura uma nova tabela definindo o nome das colunas e os tipos de dados que ela aceitará.

Exemplo SQL:

CREATE TABLE clientes ( id int NOT NULL, nome varchar(255) NOT NULL, email varchar(255) );
